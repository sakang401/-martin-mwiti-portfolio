## Requirements
- Node.js 18 or newer
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite.

## Build for production
```bash
npm run build
npm run preview
```

## Publish on GitHub
Create a new empty repository on GitHub, then open this project folder in a terminal and run:
```bash
git init
git add .
git commit -m "Initial portfolio website"
git branch -M main
git remote add origin https://github.com/sakang401/martin-mwiti-portfolio.git
git push -u origin main
```
If you name the repository differently, replace the URL in the `git remote add origin` command with your repository's HTTPS URL.
